# Gargantua (buco nero)

Esperimento visivo in `/anteprime/buco-nero/`: un buco nero disegnato in Canvas 2D, in un
unico `index.html` senza dipendenze. Non è un sito per un cliente.

- **Comandi**: `Spazio` (o un tocco) ferma l'espansione, `0` congela il timer, `R` fa
  ripartire tutto.
- Non ha il meta `anteprima-scadenza`: l'Edge Function non la fa scadere.
