# Motorsport

Pagina unica per un'attività di gomme e ricambi da competizione (auto e moto da pista), in
`/anteprime/motorsport/`. Vedi [anteprime/README.md](../README.md) per le regole comuni.

- **File**: `index.html` e `style.css`, senza JavaScript e senza build particolare: Vite li
  copia in `dist/`.
- **Contenuto**: navigazione, hero, chi siamo, servizi, modulo di richiesta preventivo, contatti.
  Testi e contatti sono d'esempio e il modulo non è collegato a nessun servizio.
- Non ha il meta `anteprima-scadenza`: l'Edge Function non la fa scadere (vedi il README di
  `anteprime/`).
