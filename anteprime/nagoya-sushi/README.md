# Nagoya Sushi

Anteprima riservata, in `/anteprime/nagoya-sushi/` (vedi [anteprime/README.md](../README.md) per protezione, scadenza e regole comuni).

Concept "Il taglio", scena Three.js
pinnata (`anteprime/nagoya-sushi/src/`). La scadenza è il meta `anteprima-scadenza`
nella pagina: dopo quella data resta solo "Anteprima scaduta, contatta Prisma Locale".
La fa rispettare anche il server (vedi [la protezione lato server](../README.md#protezione-lato-server)).
Immagini statiche e immagine social: `node anteprime/nagoya-sushi/render.mjs` con il dev server attivo.
